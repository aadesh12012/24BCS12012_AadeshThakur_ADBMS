ADBMS Technical Audit & Integrity Engine

Database constructs enforcing transactional integrity and security rules

Stored Procedures

sp_deposit_money, sp_withdraw_money, sp_transfer_money implement row-level locks (FOR UPDATE) and strict ascending lock acquisition order to prevent deadlocks.

PL/pgSQL Triggers

trg_before_transaction_insert and trg_after_transaction_insert automatically intercept transactions > ₹50,000 and bursts > 3 tx/min.

Compensating Rollbacks

When an admin rejects a flagged transaction via sp_resolve_fraud_alert, funds are atomically reverted to the sender.

Ledger Functions

fn_calculate_ledger_balance audits stored account balance against the cumulative sum of deposits, withdrawals, and transfers.
